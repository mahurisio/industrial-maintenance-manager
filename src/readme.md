# Carpeta src

Esta carpeta contendrá el código fuente principal del proyecto Industrial Maintenance Manager.

La estructura inicial del backend estará organizada así:

```text
src/
├── main.py
├── app.py
├── database.py
├── models.py
├── routes/
└── services/
```

## Propósito de cada archivo

- `main.py`: punto de entrada de la aplicación.
- `app.py`: configuración principal del backend.
- `database.py`: conexión y configuración de la base de datos.
- `models.py`: definición inicial de entidades como activos, órdenes de trabajo, técnicos, clientes y repuestos.
- `routes/`: rutas o endpoints de la aplicación.
- `services/`: lógica de negocio del sistema.

Esta estructura podrá cambiar a medida que el proyecto crezca.
